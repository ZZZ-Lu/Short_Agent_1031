## 3. 轮廓几何

### 3.1 它是怎么来的（理解用，不要用来"重新生成"）

这不是用钢笔工具拉的贝塞尔。它是一条**曲率函数**积分出来的曲线，分三段：

```
从尖端出发沿轮廓走：
  ① 肩膀段  s ∈ [0, ur]     曲率 κ 从 1/r 用 smoothstep 降到 0.05/r
  ② 圆体段  s > ur          曲率 κ = 1/r，恒为精确正圆
  ③ 尖角                     唯一的一个角，锐角 67.54°
```

为什么必须这么做：如果身体是正圆、边是直线，两者相切处曲率会从 `1/r` 瞬降到 0（掉 92%）。数学上相切成立，但人眼会按圆的曲率外推，看到轮廓向内塌 → 读作"被掐了一下"。把曲率分 29° 平滑过渡，跳变降低 334 倍，接缝消失。

**关键数值（归一化空间：r = 1，尖端在原点）**

| 参数 | 值 | 说明 |
|---|---|---|
| `ur` | **29.0°** | 肩膀段的转角跨度 |
| `w` | **0.05** | 肩膀末端的曲率 = 0.05 × 体曲率 |
| `phi` | **33.768°** | 半边尖角 |
| 尖角（全角） | **67.54°** | = 2 × phi |
| 对称轴方向 | **45°**（尖端→圆心） | 即 (cos45, sin45) |
| `d/r` | **2.033** | 尖端到圆心距离 ÷ 半径 |

## 4. 眼睛

### 4.1 坐标（这是最终值，右移过 4.5）

| 项目 | 左眼 | 右眼 |
|---|---|---|
| `cx` | **44.885** | **54.115** |
| `cy` | **44.600** | **45.400** |
| `rx` | **2.83** | **2.23** |
| `ry` | 2.83（动画会改） | 2.23（动画会改） |

| 派生量 | 值 |
|---|---|
| 两眼间距 | **9.23** |
| 右眼比左眼低 | **0.80** |
| 左眼半径 ÷ 右眼半径 | 1.269 |
| 眼睛对的中点 | **(49.5, 45.0)** |
| 体中圆心到眼睛对中点 | 横向偏 1.17，纵向偏 5.68（略偏上） |

> 眼睛对的中点在 x=49.5，体圆心在 x=50.674。眼睛**不是**几何居中，是略偏左 1.17——但因为左眼大、右眼小，视觉重量正好平衡。不要"对齐到 50.674"。

### 4.2 眼睛必须是孔，不是涂色

这是硬性要求。眼睛用 `<mask>` 从白色形体上**挖掉**，透出底板：

```xml
<mask id="me" maskUnits="userSpaceOnUse" x="0" y="0" width="92" height="92">
  <rect width="92" height="92" fill="#fff"/>
  <ellipse cx="44.885" cy="44.6" rx="2.83" ry="2.83" fill="#000"/>
  <ellipse cx="54.115" cy="45.4" rx="2.23" ry="2.23" fill="#000"/>
</mask>
<path fill="#FFFFFF" mask="url(#me)" d="..."/>
```

**为什么不能用涂色**：旧版把眼睛画成 `fill="#504587"`（底板色）的椭圆。只要底板换色（深色卡、图片背景、反白标），那两点就会露出紫斑。必须用 mask 挖孔，孔是透明的，任何背景下都正确。

`maskUnits="userSpaceOnUse"` 不能省——默认的 `objectBoundingBox` 会让 mask 坐标系跟着被遮罩元素缩放，眼睛就跑了。

### 4.3 边界安全

眼睛离轮廓的最近距离（圆弧侧）约 **9.9 单位**。思考态最不利情况下（轨道右移至极限 + 摆动 +1.7°），右眼外沿到形体的右边界仍有 **14.8 单位**余量。眼睛不会碰到轮廓。

## 5. 动效 · 待机（idle）

三个通道并行，周期互不整除——这是"不像机器"的全部机制，不要为了"整齐"去调成公约数关系。

| 通道 | 周期 | 幅度 | 作用对象 |
|---|---|---|---|
| 眨眼 | **3.2s** | ry → 18% | 两只眼睛的 `ry` |
| 扫视 | **7.6s** | ±1.05 / ±1.05 | 两只眼睛的 `cx` `cy` |
| 呼吸 | **5.6s** | 1 → 1.025 | 整体 `scale`，中心 (46.64, 46.64) |
| 摆动 | **5.2s** | ±0.55° | 整体 `rotate`，中心 **(20, 20)** = 尖端 |

3.2 / 7.6 / 5.6 / 5.2 **互不整除**，四通道永远不同时归位。

**扫视节拍**（7.6s 内四个注视点，每点停 0.1–0.2 就换，然后长停）：

| 段 | keyTime | Δx | Δy | 含义 |
|---|---|---|---|---|
| 1 | 0 → 0.16 | +0.85 | −0.75 | 右上，长停 |
| 2 | 0.18 → 0.44 | −0.95 | −0.55 | 左上，长停 |
| 3 | 0.46 → 0.68 | +1.05 | +0.45 | 右下，长停 |

## 6. 动效 · 思考（think）

| 通道 | 周期 | 幅度 | 作用对象 |
|---|---|---|---|
| 轨道 | **0.9s** | 半径 = 0.46 × 该眼半径 | 两只眼睛的 `cx` `cy`，8 点圆周，linear |
| 眯眼 | **2.8s** | 右眼 ry → 78% | 只有右眼，左眼 ry 恒定 |
| 呼吸 | **3.2s** | 1 → 0.986（**收**，非涨） | 整体 `scale`，中心 (46.64, 46.64) |
| 摆动 | **1.9s** | ±1.7° | 整体 `rotate`，中心 (20, 20) |

三处和待机不同，都是刻意的：

- **呼吸方向反转**：待机是扩张（1.025，放松），思考是收缩（0.986，收拢专注）。
- **摆幅放大 3 倍**（0.55° → 1.7°），周期缩短（5.2 → 1.9），读作"费劲"。
- **只有右眼眯**，左眼不动。单侧眯眼 = 疑惑/权衡。双眼同时眯会读成困了。

轨道偏移量：左眼 0.46 × 2.83 = **1.3018**，右眼 0.46 × 2.23 = **1.0258**。

## 7. 合成结构（DOM 顺序不能乱）

```
<svg viewBox="0 0 92 92">
  <defs>  渐变 + mask                              ← 先定义
  <rect>  底板 92×92 rx 20.6，fill=渐变             ← 最底层
  <g>     animateTransform: rotate 绕 (20,20)       ← 摆动在外层
    └ <g transform="translate(46.64 46.64)">
       animateTransform: scale                      ← 呼吸在内层
       └ <g transform="translate(-46.64 -46.64)">   ← 把缩放中心挪回来
          └ <path fill="#FFF" mask="url(#me)">      ← 白形，被 mask 挖孔
```

**两个变换轴为什么要分开：**

- 摆动的轴是 **(20, 20)**，即尖端。身体像挂着的重物在晃，有重量。
- 呼吸的轴是 **(46.64, 46.64)**，即白形质心。缩放时四边均匀进出。
- 如果两个都用体圆心（50.674, 50.674），摆动会变成"整块左右轻晃"，失去悬挂感——这是被否过的方案。

**嵌套顺序不能反**：先 rotate 再 scale（rotate 在外），否则呼吸会把摆动角度也一起缩放，幅度就不准了。

## 11. 复刻步骤

1. **建画布**：`<svg viewBox="0 0 92 92">`，`width/height` 按需给，但 viewBox 必须是 92。
2. **贴渐变底板**：`<rect width="92" height="92" rx="20.6">`，渐变 `#5F509F → #544686` 垂直。
3. **抄路径**：从 3.3 节原样复制整条 `d`，`fill="#FFFFFF"`。
4. **加 mask**：两个 `<ellipse>` 用 `fill="#000"` 画在白色 `<rect>` 上，坐标见 4.1，`maskUnits="userSpaceOnUse"`。
5. **套变换**：外层 rotate (20,20) → 内层 scale (46.64,46.64) → 反平移 → path。
6. **挂动画**：从第 5 / 6 节整段复制。
7. **跑验收清单**（第 9 节），全部通过才交付。

**最容易出错的三处**（按出错概率排序）：

1. mask 漏了 `maskUnits="userSpaceOnUse"` → 眼睛跑到画布外或缩成一团。
2. 变换嵌套顺序反了（scale 在外）→ 呼吸时摆动角度被一起缩放。
3. 抄路径时被编辑器自动折行插入空格 → `A` 命令的 flag 位错位，图形炸开。

## 附：设计意图（改之前先读，防止"优化"掉关键特征）

这个图标**不是**要"看起来像 AI"。它要读作**一个有智能的东西**，靠三件事：

1. **收敛**——从宽到窄、从圆到尖。有收敛 = 在做判断；均匀对称 = 自然生成物。
2. **落点**——尖端指向某个方向，不是悬在空中。自然物（水滴、叶芽）有方向但没有靶子。
3. **不完全闭合**——眼睛是孔，是"缺席"。观看者要自己补上"它在看"，这个补的动作被体验为"理解"，理解被归因给图形，于是"它有意图"。

**"聪明"的反面不是"死"，是"用力"。** 所以这套资产的克制是刻意的：只有两个孔、四个通道、幅度都在 3% 以内。任何"再加一点效果"的建议，方向都是错的。
