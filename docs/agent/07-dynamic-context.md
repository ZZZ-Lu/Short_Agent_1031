# Agent 按轮选择上下文

每个任务初始为 0 级，适合全局理解和规划；1 级适合执行具体步骤。层级只表示思考范围，不创建子 Agent，也不限制 Agent 回到全局或继续局部执行。

每轮提供精简工具目录和提示词模块目录，以及当前层级。仅当前选择的工具和提示词模块以完整内容注入；`sys.selectContext` 是始终可用的系统控制工具，Agent 可用它选择下一轮的 `level`、`tools` 和 `prompts`。选择替换上次选择，在下一轮生效。用户在设置中禁用的工具不可被选择或注入。完成和提问控制工具遵循各自设置。

任务目标、计划、笔记、工具事件与运行状态由现有 Runtime 保存，不随层级切换清空。用户可以在运行追踪中查看服务端实际注入的层级、工具、提示词模块和模型请求。提示词模块当前包括剧本、资产、图像生成及页面操作，可在 `src/agent/contextPolicy.ts` 中扩展。

工具选择失败会作为工具结果反馈给 Agent；无效或禁用的工具不会执行。UI 工具的可见性与动作约束保持不变。
