# Agent 后台工具优先原则

Agent 默认按任务需要调用后台工具，读取当前项目数据、执行操作和生成。用户要求演示、需要核对界面呈现或能力只能通过界面完成时，可调用页面观察与 UI 操作。两条路径应复用相同业务规则、校验、持久化和撤销能力。

后台工具读取受当前项目与用户权限约束，返回数据来源，并对较长结果分页。页面观察仍只描述当前可见的 UI 事实；后台工具可返回当前项目中尚未显示的业务数据。工具输出和失败进入任务记录，Runtime 不按照任务标题编排固定步骤，也不要求每个任务执行鼠标动作。

当前已注册的后台只读工具是 `script.directory`、`script.read`、`script.search` 和 `asset.list`，分别提供分集目录、正文、全文搜索及角色、场景、道具列表。`card.generate` 是现有生图工具；剧本及资产的后台写入与生成工具需要接入真实业务能力后再注册。设置页面保留 `page.inspect`、`ui.actAndObserve` 与 `guide.lookup`。首轮自动页面观察默认关闭，用户可自行启用。

本原则取代早期文档中强制通过 UI 获取项目事实和完成任务的要求；旧文档中关于可见目标、鼠标动作和页面观察的规则仍适用于选择 UI 路径的场景。
